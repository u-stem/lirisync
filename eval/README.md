# 評価セット（eval）

整列の精度を、手で付けた正解時刻と比べて測ります。音源と歌詞は著作物なのでコミットしません。コミットするのは正解ラベルと評価結果だけです。

## 曲の置き方

```text
eval/songs/<slug>/
├─ labels.txt   # 正解ラベル（コミットする）
├─ lyrics.txt   # 歌詞。1 行が 1 表示行（.gitignore 済み）
└─ audio/       # 音源（.gitignore 済み）
```

## 正解ラベルの付け方

Audacity のラベルで付け、「ラベルを書き出す」で `labels.txt` に保存します。

- 各行の歌い出しにラベルを置きます。点ラベルでも範囲ラベルでも構いません。範囲ラベルは開始時刻だけを使います
- ラベルの文字列には、歌詞ではなく `lyrics.txt` の行番号（1 始まり）を書きます。ラベルはコミットするので、歌詞そのものを入れないためです
- 精度は 50 ms 程度を目安にします。合格基準が「中央誤差 0.5 秒以内」なので、ラベルの誤差はそれより十分小さくします
- 歌わない行（空行、「（間奏）」など）にはラベルを付けません。ラベルのない行は評価から外れます

読み込みは厳格です。行番号でないラベル、同じ行への 2 つ目のラベル、終了が開始より前の範囲、周波数の選択を含む行は、行番号付きのエラーで止まります。`lyrics.txt` にない行や空行を指すラベルも、エラーにします。

## 指標

- **一致率**：ラベルのある行のうち、整列が開始時刻を出せた行の割合
- **行開始の中央誤差**：一致した行の「予測と正解の開始時刻の差の絶対値」の中央値。全曲の行をまとめてから中央値を取ります
- **繰り返し行の取り違え率**：同じ文面の行（NFKC で揃えて比較）について、予測の開始時刻が自分の正解より、別の出現の正解に厳密に近い行の割合。同じ距離は取り違えに数えません。比べる相手のいない行は数えません

- **行開始の P90**：一致した行の誤差の 90 パーセンタイル（最近順位法）。中央値では見えない裾を測ります
- **粗大誤差率**：一致した行のうち、誤差が 1 秒を超える行の割合。一致しなかった行は一致率の側で数えます
- **沈黙誤差率**：高信頼（既定は 0.8 以上）と出した行のうち、誤差が 1 秒を超える行の割合。信頼度を信じた利用者が確かめない誤りです
- **信頼度の AUROC**：誤差 1 秒以内の行と粗大誤差の行から 1 つずつ選んだとき、前者の信頼度が高い確率。同じ値は半分と数えます。0.5 は当て推量と同じです

信頼度を使う 2 つの指標は、整列器が信頼度を出すときだけ計算します。一致した行の一部にだけ信頼度がある出力は、整列器の誤りとしてエラーにします。

精度の合格基準は、中央誤差 500 ms 以下かつ一致率 85% 以上です。
